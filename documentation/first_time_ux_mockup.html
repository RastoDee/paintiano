Prečo táto cesta

  • Inverted onboarding (Duolingo princíp) — USE first, then optionally customize
  • 3-second value — user vidí magic okamžite, nie po nastavovaní
  • Cognitive load = zero pri prvom dojme (1 tlačidlo: PAUSE)
  • Static welcome → live demo (Gen Z preferencia)
  • Progressive disclosure — cockpit existuje, ale je skrytý kým user nepýta
  • Plain-language termíny (Bold namiesto φ Phi, Bright namiesto Spectral)
  • Žiadny edit mode — všetky chipy tappable always
  • „Surprise me" ako primárna akcia — žiadne rozhodovanie
