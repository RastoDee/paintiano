CHANGE LOG (this delivery):
  · NEW Setup picker — top-menu item between Guide and Pro. Opens a modal
    with two checklist sections: palettes (5) and artists (16 + Mosaic family).
    Choice persists in localStorage. Min 1 + 1 required. Free tier sees Pro
    artists with 🔒 — checking saves the preference, paint still hits paywall.
  · Setup-picker filters propagate through the canvas pickers:
      - Palette tab pickers (image + non-image) — only show selected modes,
        grid columns auto-fit (was hard-coded 4-col / 5-col).
      - cycleColorFs (FS palette button) — cycles only through selected modes.
      - Artist tile pairs — pair hidden if neither side selected; when only
        ONE side selected, pair behaves as a single-toggle (no A↔B flip).
      - Mosaic chip — hidden when Mosaic family not selected.
      - SHUFFLE_POOL — filtered to selected artists; MOSAIC_FAMILY included
        only if Mosaic family selected. Lock mode a no-op if family disabled.
  · Active-mode safety: if user disables the currently-active palette/artist,
    falls back gracefully (palette → Harmony or first available; artist → null).
  · Demo nav item TEMPORARILY HIDDEN — kept in source as a JSX comment so it
    can be restored in one paste. demoArmed/demoPlay/demoReelStop logic is
    fully untouched, only the nav entry hidden.
